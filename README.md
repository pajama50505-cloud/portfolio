# 김용우

저는 대규모 트래픽 환경에서, 백엔드를 중심으로 웹 서비스 전반을 설계, 개발, 운영, 고도화해온 개발자입니다.<br/>
요구사항 분석부터 아키텍처 설계, 성능 최적화, 장애 대응까지 전 과정을 주도하며, 운영 환경에서의 안정성과 확장성을 가장 중요한 기준으로 개발해왔습니다.<br/>
레거시 시스템의 안정화 및 고도화와 신규 플랫폼 구축 PL 경험을 보유하고 있으며,<br/>
웹 서비스의 구조와 실행 흐름, 트래픽 특성 및 장애 패턴을 고려한 현실적인 백엔드 설계와 개선에 강점을 가지고 있습니다.<br/>
서비스 특성에 맞는 신뢰도 높은 시스템을 구축하고 즉시 운영 환경에 기여할 수 있는 웹 서비스 개발자입니다.<br/>
최근에는 DINOv2 기반 이미지 유사도 검색 시스템을 설계·검증하고, LLM 기반 Pull Request 코드리뷰와 CI/CD 배포 프로세스 자동화를 구축하는 등 AI 기술을 검색, 코드 품질 향상, 개발 생산성 및 운영 자동화 영역에 적용해왔습니다.<br/>


## 주요 경험 & 핵심 역량

- 신규 프로젝트 PL 경험 기반 고객사 요구사항 정의부터 설계, 개발, 오픈, 운영까지 주도한 경험
- 광고 구매·인벤토리 차감·송출 데이터 생성 등 복잡한 업무 로직 구현
- 대용량 로그 데이터 처리 및 배치/자동화 시스템 구축
- 대규모 광고 트래픽 서비스 풀스택 개발 및 인프라 운영 경험
- RESTful API 개발, RDBMS(MySQL) 기반 데이터 모델링 및 성능 최적화
- LLM 코드리뷰, CI/CD를 연결한 개발 워크플로우 자동화 경험
- AI 개발 보조 환경을 활용해 API 개발, 리팩토링, 장애 분석 효율을 개선하며 생산성을 높인 경험을 보유
- 이미지 특징 추출 모델과 벡터 검색 엔진을 결합한 검색 시스템 기술 검증

## 영상 광고 운영 청약 시스템 유지보수 및 고도화

`2015.11 - ing` · 풀스택 개발 / 서비스 운영 및 고도화

- 광고, 소재, 타겟팅과 판매 청약을 통합 관리하는 고객사별 시스템 개발·운영
- 고객사 요구사항 수집, 우선순위 조율 및 기능 개선 반영
- 트래픽 급증과 장애 발생 시 실시간 대응
- 레거시 리팩토링과 쿼리·인덱스 튜닝으로 평균 응답시간을 300ms에서 80ms 수준으로 개선
- Python/Django 기반 점진적 마이그레이션과 관리자 UI/UX 리뉴얼
- AWS 기반 서비스 모니터링과 인프라 운영
